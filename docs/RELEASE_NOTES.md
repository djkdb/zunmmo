# 릴리스 노트

## v0.1.0-beta — 첫 클로즈드 베타

내 하루를 MMORPG처럼 플레이하는 LIFE RPG의 첫 베타예요.

**모험의 시작**
- 이메일 코드(또는 Google)로 입장 → 이름과 외형을 고르면 나만의 모험가가 생겨요.
- 게임 마스터가 고른 가벼운 퀘스트 템플릿으로 첫날부터 바로 시작할 수 있어요.

**퀘스트**
- MAIN · DAILY · SIDE · BOSS 네 가지 퀘스트. 메인 퀘스트라인은 단계를 줄 단위로 한 번에 적고, 마지막 단계를 보스로 만들 수 있어요.
- 완료는 한 번 탭. 실수했다면 토스트의 "되돌리기"로 바로 취소돼요.
- 기한이 지나도 XP를 잃지 않아요. "기한 만료"로 보일 뿐, 언제든 다시 도전할 수 있어요.

**성장**
- XP와 레벨, 다섯 가지 스탯(INT·FOC·VIT·SOC·CRE)이 실제 행동에 따라 자라요.
- 16개의 업적 배지, 레벨업 장면, 보스 처치 연출.
- 캐릭터 화면에서 이번 주 XP, 연속 모험 일수, XP 기록을 볼 수 있어요.

**오늘의 모험 & 캘린더**
- 게임 마스터가 마감·보스·습관·퀘스트라인·스탯 균형과 하루 시간을 보고 오늘 할 퀘스트를 골라 줘요. 외부 AI 없이, 같은 날엔 같은 추천이에요.
- 주간/월간 캘린더에 마감과 일정을 함께 보고, 고정 일정은 그날 추천 시간에서 빠져요.

**그 밖에**
- 홈 화면에 설치할 수 있어요 (PWA).
- 설정에서 시간대, 하루 시작 시각, 하루 모험 시간을 바꿀 수 있고, 계정과 모든 기록을 직접 삭제할 수 있어요.

**알려진 한계**
- 오늘의 모험에서 추천을 하나씩 빼거나 더할 수는 아직 없어요 ("다시 추천받기"만 가능).
- running · working · exercising 캐릭터 동작은 다음 업데이트에서 그려져요.
- 알림, 외부 캘린더 동기화, 친구 기능은 아직 없어요.
